# ZeeFrames — «Чем сайт отличается от площадок?»

На странице два варианта блока, текст — блок `#rent` из amdc-site/v2.

**1. Бенто** (`sb.css`, классы `zsb-`) — по образцу Formio «From chaos to clarity»
(№16 подборки https://semenovmak111-create.github.io/zeeframes-sravnenie/): тёмное бенто,
в каждой ячейке минус площадки сверху и ответ своего сайта снизу (выровнены subgrid),
высокая белая CTA-ячейка справа (жёлтая при наведении) и стеклянный пузырь на стыке.

**2. Таблица** (`st.css`, классы `zst-`) — по образцу GutGutGoose «vs. generic probiotics»
(№30 подборки): кремовая секция с чёрной скруглённой карточкой (как блок контактов zeeframes),
заголовок по центру, матрица «что сравниваем / свой сайт / площадка» с волосками и номерами
строк «Six reasons» с /about; колонка своего сайта — на плашке `--color-black-180` во всю
высоту, ✓ в лаймовой коробке `.card-icon` (заливается лаймом при наведении на строку).
До 820 px каждая строка складывается в стопку: измерение, сайт на плашке, площадка.

Встраивание: нужная `<section>` из `index.html` + её CSS. Без JavaScript.
`proverka/` — снимки 1440 / 1024 / 900 / 390 и `shoot.py`, не публикуются.

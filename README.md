# ZeeFrames — «Чем сайт отличается от площадок?»

Блок сравнения по образцу Formio «From chaos to clarity» (№16 подборки
https://semenovmak111-create.github.io/zeeframes-sravnenie/), в дизайн-системе zeeframes.com:
тёмное бенто, в каждой ячейке минус площадки сверху и ответ своего сайта снизу
(ответы соседних ячеек выровнены subgrid), высокая белая CTA-ячейка справа
(жёлтая при наведении) и стеклянный пузырь на стыке. Текст — блок `#rent` из amdc-site/v2.

Встраивание: секция `<section class="zsb">…</section>` из `index.html` + `sb.css`.
Классы `zsb-`, без JavaScript. `proverka/` — снимки 1440 / 900 / 390, не публикуются.
